# 小小城镇（简体中文版）

基于 Derek Yao 的 [Little City](https://github.com/yaoderek/littlecity.io) 发布包制作的独立汉化工程。默认简体中文，不提供英文切换。保留原游戏的程序逻辑、3D 素材和存档格式。

`main` 提供原版简体中文构建。`jiangnan` 用于江南风格开发，继承 `v6` 的场景与建筑改动。历史版本可通过 `v1` 至 `v6` 和 `v5-audit` 标签检出。

## 构建

固定上游版本：`af6eac24ff21cbf027d4d33fd8219237a559f5b5`（对应上传的 gh-pages ZIP）。

```bash
python -m pip install -r requirements.txt
python build.py
```

或者使用已有 ZIP 离线构建（依赖已安装）：

```bash
python build.py --source littlecity.io-gh-pages.zip
```

输出：`dist/`，可直接静态托管。无需运行 Node 后端、数据库或游戏服务器。Node 可用时自动执行 JavaScript 语法检查。构建时生成 `localization-report.json`，记录未匹配静态文本供进一步复核。

## 江南水乡试验分支

当前开发分支为 `jiangnan`。初始版本从 `v6`（原 `art-jiangnan-v6-buildings`）接续，并合入 `main` 的汉化修复。`v6` 与 `v5-audit` 的标签指向同一历史提交，包含场景菜单验收修复。Cloudflare Pages 若需预览当前版本，构建分支使用 `jiangnan`。

### 枕水古镇

新访客默认打开「枕水古镇」，已有存档的玩家可从菜单的「江南场景」切换。河道一侧保留窄岸街，另一侧的低层排屋贴水而建，从后巷进出。三座石拱桥连接两岸，四处石阶水埠可停靠乌篷船。拐进支巷可到院落、集市和园亭。默认镜头沿着河道照见临水木格窗、瓦檐和石埠。

民居参照苏州平江和同里的低层砖木房屋，用粉墙、平脊硬山小青瓦和部分阶梯形封火墙组织街面。民居改用平齐木窗，并减少山墙开窗。铺面、出檐和市集摊棚采用木构与瓦面。[建筑参考与验收标准](jiangnan-architecture.md)

地形和建造内容使用原有存档字段。构建验证地形保存与还原、三座桥、四处水埠、乌篷船、主要入口步行连通性及民居屋面和临水格窗。该预设包含 322 个方块和 225 个地面格。

### 元夕灯市

从「菜单 → 江南场景 → 元夕灯市」进入日落后的桥头灯市。镜头同时照见廊桥、走马灯、围读灯谜的人和河岸石埠。孩子提兔灯过桥，花灯和汤圆摊夹街布置，带瓦篷的花船沿河驶过。可在右上角切换昼夜。[元夕灯市建模记录](lantern-town-design.md) · [灯会调研与画面验收](lantern-festival-research.md)

### 江南建筑与人物模型

- 民居屋面加入连续曲坡、角部抬升和实体滴水瓦口，普通烟囱改为低矮瓦帽灶烟口。宽窗使用菱格，长窗及商铺使用方格，店门和部分厅堂入口增加木门罩、托木和石础。
- 园亭的屋面、檐口及脊线共用翘角高度。使用锥形塔顶的塔改为八角双叠檐，保留原有用途及挂载点。
- 居民网格分为躯体、双臂和双腿。短衫、长裙、围裙、斗笠、两种童装和守卫服复用现有动作骨架，船工使用斗笠，水手使用短衫或围裙。发髻、袖口、交叠领和裙褶有单独几何。
- 低面数人物进行了站立、步行、坐下、垂钓和搬运的网格检查。建造方块、场景种子、寻路和存档继续使用现有数据格式。教堂、温室、风车、婚礼服饰附件等特殊资产仍沿用现有模型。
- 江南场景与一键凉亭通过构建时生成的固定引擎接口调用原生地形、建造及解析函数。打开预设时载入已验证的完整地图，保证默认树木不会阻挡预设建筑。浏览器检查使用场景种子和建造后的实际建筑数据确认切换结果。

造型参考：[同里古镇传统民居](https://dfzb.suzhou.gov.cn/dfzb/szdq/201604/db3c6af806fb487ca70e2270e2f6a75a.shtml)、[苏州园林木窗](https://ylj.suzhou.gov.cn/szsylj/ylys/202404/613a96d3071d489d82e3b0f303e41754.shtml)、[中国丝绸博物馆馆藏江南衫裙](https://www.chinasilkmuseum.com/zggd/info_21.aspx?itemid=1870)。

本分支在构建阶段自动执行 `art_style.py`，修改 13 组配置、6 套房屋外观（原存档 ID 保持）。建议进入菜单选择河谷岛屿，再生成河畔小镇。粉墙灰瓦、宽檐、青石道路、灰绿河水、较高拱桥、素木门窗与低饱和植被构成第一轮美术原型。

该版本仍沿用原有西式建筑几何、角色、船只类别与事件规则；马头墙、曲面飞檐、乌篷船、灯笼、园林漏窗尚未建模。原始 ZIP 上的 13 组参数和 6 套房屋记录均匹配，修改后的全部 JS 通过 `node --check`；浏览器本地页面因环境访问策略无法加载，尚无实机截图或完整集成测试。Pages 构建命令不变，使用本分支即可预览。

## V5：功能街区、组合建造与原生几何审查

- 三个固定场景分别追加 4×4 沿街集市（23 条指令）、5×5 田园菜圃（25 条）、5×5 围合园林（51 条）。使用现有 can/apply/resolve 接口检查并回放，固定坐标只适用于三个已验证种子，不是任意地图上的通用规划器。
- 枕水古镇新商铺和摊位沿新广场组织，保留后街。田园水村新增菜圃和农居，园林水镇新增亭子和园墙。原生角色为 shop、stall、kitchen-garden、bandstand 等，尚未增加独立茶楼、祠堂、书院或相应生活事件。
- 精细建造的「一键凉亭」新增真正的 2×2 组合工具：4 个双层柱、4 块顶盖共 12 条指令。全批预检查，原生 ghost preview，editAll 提交，单次撤销/重做。拒绝不平、越界、有建筑、地面装饰或边界物的区域。观察/切换普通工具清除组合模式，滚轮长度和连续拖动不再作用于该模式。其余快捷入口如码头、院墙、街道按真实工具命名；船、月洞门与街灯仍由规则生成。
- 几何审查发现宽山墙重复阶梯和压顶叠合。将阶梯山墙限制为单格跨宽、五级减为三级、相邻压顶避免水平重叠、非玻璃屋顶采用深瓦色檐板。亭子改为深红木柱与深色梁枋。并非所有屋顶相交问题均已解决。

## V5 验收修复分支（art-jiangnan-v5-audit）
